# Crypto Whale & Price Monitoring Telegram Bot 🚀

An automated Python-based Telegram bot that monitors real-time Ethereum (ETH) market prices and wallet activities using public APIs and Termux.

## 🌟 Features
- **Real-Time Price Tracking:** Fetches live ETH prices via CoinGecko API.
- **Automated Telegram Alerts:** Sends periodic market updates directly to a specified Telegram Chat/Channel.
- **Lightweight & Keyless:** Designed to run seamlessly in low-resource CLI environments (Termux / Linux servers) without API keys.

## 🛠 Tech Stack
- **Python 3**
- **Requests Library**
- **Telegram Bot API**
- **CoinGecko API**
